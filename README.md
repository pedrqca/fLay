# LAYN

O **LAYN** é um sistema para **controle de jornada e banco de horas**, desenvolvido para facilitar o registro, acompanhamento e gerenciamento das horas trabalhadas.

## Funcionalidades

### ⏱️ Controle de jornada

- Registro das horas trabalhadas.
- Visualização dos registros de jornada.
- Edição dos registros existentes.
- Exclusão de registros.
- Organização dos registros por data.

### 📊 Banco de horas

- Acompanhamento do saldo de horas.
- Visualização das horas acumuladas.
- Controle das horas positivas e negativas.
- Histórico das movimentações do banco de horas.

### 🔄 Compensação de horas

- Registro de horas utilizadas para compensação.
- Definição da data da compensação.
- Registro da quantidade de horas ou minutos.
- Adição de uma descrição para cada compensação.
- Edição e exclusão das compensações.

### 🧾 Comprovantes

- Adição de comprovantes aos registros.
- Visualização dos comprovantes cadastrados.
- Organização dos comprovantes relacionados às atividades.
- Exclusão de comprovantes.

### 👤 Gerenciamento de usuários

- Cadastro e gerenciamento de usuários.
- Associação dos registros de jornada ao usuário.
- Controle individual das informações de banco de horas.

### 📋 Histórico

- Visualização dos registros realizados.
- Acompanhamento das alterações e movimentações.
- Consulta das informações de jornada ao longo do tempo.

---

## 🎯 Objetivo

O LAYN tem como objetivo centralizar o **controle de jornada, banco de horas, compensações e comprovantes** em um único sistema, tornando o acompanhamento das horas trabalhadas mais simples e organizado.
